## Phase D: Universal WHOIS Parser

- [x] D.1 **Create WhoisParserInterface**: Write `src/Parser/Whois/WhoisParserInterface.php` with method `parse(string $rawResponse, string $serverHostname): StructuredResult`. This is the common interface for both universal and server-specific parsers.
- [x] D.2 **Write universal WHOIS parser**: Create `src/Parser/Whois/WhoisParser.php` implementing `WhoisParserInterface`. This is the key component replacing 143 Novutec templates. It must: (a) detect key:value patterns in WHOIS text, (b) normalize common field names across servers (e.g., "Domain Name:", "domain:", "domain name:"), (c) extract: domain name, registrar, dates (created/updated/expires), nameservers, status codes, contacts (registrant/admin/tech/abuse with name/org/email/phone/address), (d) handle character encoding via mbstring (best-effort UTF-8 conversion), (e) return partial StructuredResult for partially parseable responses, (f) throw ParseException only for completely unparseable input. Reference the v1 extractors for field name patterns but do NOT reuse v1 code. Verify: can parse a Verisign .com WHOIS response correctly.
- [x] D.3 **Write parser tests**: Create `tests/Unit/Parser/Whois/WhoisParserTest.php`. Manually create 3-5 sample WHOIS fixture files for known formats (Verisign .com, RIPE IP, ARIN IP, a ccTLD like .de or .uk) in `tests/Fixture/Whois/`. Write tests that parse each and verify key fields are extracted. Verify: tests pass for all manual fixtures.
- [x] D.4 **Commit**: `git commit -m "feat(parser): universal WHOIS parser replacing 143 Novutec templates"`
